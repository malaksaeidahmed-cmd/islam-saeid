إزاي تستخدم الملفات دي؟

  1. اضغط "تنزيل" لكل ملف على حدة
  2. افتح GitHub → استبدل الملفات دي في الجذر:
    • sitemap.xml
    • feed.xml
    • robots.txt
  3. Commit changes → استنى دقيقة للنشر
  4. افتح Google Search Console → Sitemaps → ضيف sitemap.xml
  5. مهم: أعد توليد الملفات دي كل مرة تنشر مقال أو مشروع جديد
